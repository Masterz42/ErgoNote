Planned: links that open ErgoNote

ErgoNote is planned to support links that open a specific notebook page from a browser, email, chat, or another application. The operating system will use the ergonote: link type to launch ErgoNote and pass it the page to open. Depending on your operating system and browser, you may be asked to confirm before the app opens.

This feature is not available yet. ErgoNote does not currently register ergonote: with your operating system or handle an external link by navigating to its page. Copying a ErgoNote page link does not mean it can be opened from a browser today.

How registration is planned to work

  • Windows installer: register ErgoNote during installation and remove that registration

when ErgoNote is uninstalled.

  • Windows portable ZIP: provide a separate Register ErgoNote links action that you

choose to run, plus a way to undo it. Extracting the ZIP alone will not register the link.

  • macOS: declare the link type in the ErgoNote app bundle.
  • Linux: install a desktop application association for the link type.

Registration only tells the operating system which application can receive a link. ErgoNote must also find the matching notebook and page, handle links when it is already running, and explain clearly when a notebook or page cannot be found. That handling is part of the planned feature too.
