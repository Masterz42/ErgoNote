בתכנון: קישורים שפותחים את ErgoNote

התכנון הוא לאפשר ל-ErgoNote לפתוח עמוד מסוים במחברת מתוך קישור בדפדפן, בדוא״ל, בצ׳אט או באפליקציה אחרת. מערכת ההפעלה תשתמש בסוג הקישור ergonote: כדי להפעיל את ErgoNote ולמסור לו איזה עמוד לפתוח. בהתאם למערכת ההפעלה ולדפדפן, ייתכן שתתבקשו לאשר את פתיחת האפליקציה.

התכונה עדיין אינה זמינה. ErgoNote עדיין לא רושם את ergonote: במערכת ההפעלה ואינו פותח את העמוד המבוקש כשמתקבל קישור חיצוני. העתקת קישור לעמוד ב-ErgoNote לא אומרת שאפשר לפתוח אותו בדפדפן כרגע.

אופן רישום הקישורים המתוכנן

  • מתקין Windows: ירשום את ErgoNote במהלך ההתקנה ויסיר את הרישום בעת הסרת התוכנה.
  • קובץ ZIP נייד ל-Windows: יציע פעולה נפרדת בשם רישום קישורי ErgoNote שתפעילו מרצונכם, וכן דרך לבטל את הרישום. חילוץ קובץ ה-ZIP לבדו לא ירשום את הקישור.
  • macOS: סוג הקישור יוגדר בחבילת אפליקציית ErgoNote.
  • Linux: תותקן שיוך של יישום שולחן עבודה לסוג הקישור.

הרישום רק מודיע למערכת ההפעלה איזו אפליקציה יכולה לקבל את הקישור. ErgoNote צריך גם למצוא את המחברת והעמוד המתאימים, לטפל בקישור כשהאפליקציה כבר פתוחה, ולהסביר בבירור אם המחברת או העמוד לא נמצאו. גם הטיפול הזה הוא חלק מהתכונה המתוכננת.
